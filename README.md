# moncho/homebrew-tap

Homebrew formulae for macOS and Linux.

```sh
brew install moncho/tap/osc52
```

`Formula/osc52.rb` is generated by `update-osc52.sh` from the latest
[osc52 release](https://github.com/moncho/osc52/releases/latest). A daily
workflow runs it and commits any change; run the workflow by hand to pick up
a release sooner.
